## 🧩 How I Ship (Project Management Operating System)

### Step 1 — Discovery (Week 0)
- Identify stakeholders (users, buyers, ops, finance, support)
- Map workflows end-to-end (happy path + handoffs)
- Capture constraints (time, budget, tech debt, compliance)
- Define success criteria (measurable, not vibes)

### Step 2 — Scope Like an Adult (Week 1)
- Tight scope boundaries + explicit assumptions
- Tradeoffs documented (speed vs correctness vs cost)
- Phased delivery plan (MVP → Iteration → Scale)

### Step 3 — Ship With Quality (Weeks 2+)
- Acceptance criteria → QA alignment → test plan
- Release checklist: migrations, rollbacks, logs, monitoring, docs
- Change control: new requests go to backlog with impact analysis

### Step 4 — Design for Operators
- Reduce clicks, prevent errors, handle edge cases
- Guardrails: permissions, validations, safe defaults
- Clear UX for “what happens next”

### Step 5 — Launch + Learn
- Instrumentation: events + dashboards
- Post-launch review: outcomes, gaps, next sprint priorities
